# BLACKE
Portfólio estático em português, lavanda e cinza. Abra index.html ou publique a branch main na raiz do GitHub Pages.

Os painéis dos projetos são ilustrações CSS conceituais, não capturas reais. Os links existentes apontam para GitHub; falta informar URLs públicas dos sistemas e um canal direto de contato (WhatsApp ou e-mail). Não há backend nem dependências externas.
